# Wireframes · QuadraJá

Telas mobile em baixa fidelidade (largura de 360 px, tons de cinza). Elas mostram a organização de cada tela, a hierarquia das informações e os componentes que se repetem. As caixas tracejadas são anotações de comportamento.

| Arquivo | Tela | Componentes que aparecem |
|---|---|---|
| tela_01.png | Início | Header, botão primário, chips de esporte, QuadraCard compacto |
| tela_02.png | Esportes | Header, card de esporte |
| tela_03.png | Buscar quadras | campos de busca e filtro, QuadraCard padrão e QuadraCard grátis (tracejado) |
| tela_04.png | Detalhe da quadra | foto com crédito, Estrelas, selos, caixa de preço, lista de estrutura, avaliação |
| tela_05.png | Escolher horário | SeletorHorario (livre, escolhido, ocupado), botão primário |
| tela_06.png | Resumo da reserva | lista de dados, aviso da regra de cancelamento |
| tela_07.png | Pagamento | opções Pix e Cartão, formulário |
| tela_08.png | Reserva confirmada | ícone de sucesso, código, botões primário e secundário |
| tela_09.png | Login | formulário |
| tela_10.png | Cadastro | formulário (FormularioUsuario vazio) |
| tela_11.png | Minhas reservas | abas, ReservaCard com Remarcar e Cancelar |
| tela_12.png | Perfil | cartão do usuário, botões |
| tela_13.png | Cadastrar minha quadra | formulário |
| tela_14.png | Como funciona | cards de passo |
| tela_15.png | Ajuda e contato | perguntas que abrem e fecham, formulário |
